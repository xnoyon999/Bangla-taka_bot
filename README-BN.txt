BANGLA TAKA BOT (Ad SDK ছাড়া)

Render এ Environment Variables:
  BOT_TOKEN              = বটের টোকেন
  BOT_USERNAME           = বটের ইউজারনেম (@ ছাড়া)
  ADMIN_MAINTENANCE_KEY  = নিজের লম্বা গোপন পাসওয়ার্ড
(Firebase এর কোনো ভ্যারিয়েবল দেবেন না)

Webhook: https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<RENDER_URL>/bot.php

Ad SDK পরে যোগ করতে: বটে /admin → Ad Network ট্যাবে SDK লিংক বা <script> কোড বসিয়ে Save করুন।
SDK না থাকলে Poro/Lijent বাটন চাপলে "Ad SDK akhono add kora hoy nai" দেখাবে।
